# Demo corpus manifest

The public repository deliberately does not include private course material. Before a full evaluation, upload the synthetic/public-domain corpus described below and keep the filenames used in `../cases.json`.

| Material | Format | Pages/slides | Required content |
| --- | --- | ---: | --- |
| `database-lecture.pdf` | PDF | 14 | definitions, tables, normalization |
| `mechanics-handwritten.pdf` | scanned PDF | 12 | at least two photographed handwritten pages, equations, one difficult scan |
| `mechanics-diagrams.pdf` | PDF | 8 | labelled diagrams and tables |
| `research-methods.pptx` | PPTX | 14 | research-process and data-type slides |
| `writing-guide.md` | Markdown | 4 | abstract, paragraph, conclusion guidance |
| `database-examples.txt` + `mechanics-examples.txt` + `research-survey.txt` | text | 8 | worked examples |

This is a 60-page/slide minimum across PDF, scanned-PDF, PPTX, Markdown, and text. Use openly licensed or self-authored materials only. The cases are a reusable evaluation contract, not a claim that a corpus has already been benchmarked.
